# Firewall & Server Module

Quản lý Firewalld và Server metrics cho LaunchPad DevOps Ecosystem bằng **Cockpit**.

## Quick Setup

```bash
# Cài đặt Cockpit và Firewalld
./scripts/setup-cockpit.sh
```

Truy cập quản trị tại: `https://<IP_VPS>:9090`
